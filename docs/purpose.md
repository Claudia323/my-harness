# 하네스 목적

## 매번 달라지는 입력
- 사용자 플로우 1개 (PRD 16-2 목록 중 택1)
  - 무료 콘텐츠 탐색 / 유료 자료 열람 / 스킬 카드 사용 / 미션 제출
  - 내 자산 등록 / 판매 신청 / 운영자 검수

## 사용자
- 실행자: 디자이너 본인 1명
- 승인자: 기획자 (사람 승인 지점에서만 참여)

## 완료 기준 (한 문장)
선택한 플로우의 키스크린(규격·개수: rules.json `frame`)과 그에 쓰인 토큰·컴포넌트가 Figma에 있고,
judge.py S3·S4 판정 PASS(design.md 규칙 · story-service ★A/B 포함)이며,
기획자 승인(H1) 1회를 통과한 상태.

> 수치는 이 문서에 적지 않는다. 모든 값은 rules/rules.json에만 있다.
